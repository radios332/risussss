# 종이책 · PocketRisu 채팅 테마 0.2.0

PocketRisu **1.14.0**의 대화 표시 영역을 책 페이지로 꾸미는 테마입니다.
채팅방을 열면 바로 적용됩니다. **기존 입력창과 전송 버튼, 사이드바는 그대로**
사용합니다. 별도 뷰어 화면이나 이북/채팅 모드 전환은 없습니다.
CSS가 종이·글꼴·여백을 담당하고, JS가 현재 채팅방 읽기와 페이지 넘김을 담당합니다.

## 설치·이전 버전 업데이트

1. **설정 → 플러그인 → 플러그인 임포트**에서 `dist/paper-reader.js`를 선택합니다.
2. 기존 **종이책 리더**가 있으면 같은 이름의 플러그인을 업데이트할지 묻는 창에서
   업데이트합니다. 설치 후 표시 이름은 **종이책 테마**입니다.
3. 채팅방을 열 때 PocketRisu가 **메인 Document 접근**을 물으면 허용합니다.
   실제 대화 영역의 화면만 바꾸기 위해 필요한 권한입니다.

**CSS가 JS에 포함되어 있으므로 파일 하나만 설치하면 됩니다.**
`paper-theme.css`는 같은 CSS를 따로 제공하는 편집용 파일입니다.
이전 버전의 `paper-theme.json`을 다시 가져올 필요는 없습니다.
이전에 JSON으로 바뀐 앱 전체 색상을 되돌리고 싶으면 디스플레이에서 이전에
사용하던 테마 프리셋을 선택하면 됩니다. 이번 버전은 앱 전체 색상 설정을 바꾸지 않습니다.

## 사용

- 현재 열린 방의 **첫 인사말(-1), 메시지 0부터 최신까지** 읽습니다.
  다른 방의 대화 내용을 미리 불러오지 않습니다.
- **이전 / 다음**, 본문에 포커스를 둔 상태의 `←` / `→`, `PageUp` / `PageDown`,
  좌우 스와이프로 넘깁니다. 긴 메시지는 여러 쪽으로 나뉩니다.
  한 메시지의 마지막 쪽에서 다음을 누르면 다음 메시지로 이어집니다.
- **처음 / 최근**, **대화 목차**로 바로 이동할 수 있습니다.
  페이지 표시는 `현재 대화 / 전체 대화 · 현재 쪽 / 해당 대화의 전체 쪽`입니다.
- **Aa**에서 글자 크기와 종이 색을 조절합니다.
- 입력창은 항상 사용할 수 있습니다. 입력창에서 누른 화살표는 커서를 움직입니다.
- 현재 방의 내용이 바뀌면 표시를 갱신합니다. 마지막 대화를 읽고 있었다면 새 대화로
  이어지고, 과거 대화를 읽고 있었다면 읽던 메시지를 유지합니다.
- 방별 읽던 위치와 글자 크기·색은 이 브라우저에 저장합니다.
- 테마를 해제하려면 **설정 → 플러그인 → 종이책 테마**를 끕니다.

## CSS·이미지

실제 채팅 화면의 `.risu-chat .chattext` 안에 본문을 표시하므로 기존 사용자 CSS가
적용됩니다. 본문의 HTML, 인라인 스타일과 `<style>`도 지원합니다. 본문에 들어 있는
스타일은 해당 본문으로 범위를 제한합니다. PocketRisu와 동일하게 HTML 클래스에
`x-risu-` 접두사를 적용합니다.

마크다운 이미지, HTML `<img>`, 현재 캐릭터의 `{{img::이름}}` / `{{image::이름}}` /
`{{asset::이름}}` / `{{emotion::이름}}`, `{{raw::이름}}` / `{{path::이름}}`,
이미지 인레이를 지원합니다. 캐릭터 에셋·인레이는 PocketRisu의 기존 인증된 이미지
경로로 읽습니다. 외부 이미지 URL은 해당 이미지를 표시할 때 요청됩니다.

스크립트·이벤트 핸들러·iframe은 실행하지 않습니다. CBS 변수 변경, 트리거,
표시 정규식은 재실행하지 않으므로, **정규식이나 스크립트로 새로 생성하는 위젯은
원래 채팅과 다를 수 있습니다.** 모듈 전용 이름 에셋과 동영상 인레이는 이번 버전의
지원 범위에 포함하지 않습니다. 메시지 편집·재생성 등 기본 메시지 카드의 개별
작업 버튼은 테마를 끈 기본 화면에서 사용할 수 있습니다.

## 데이터 처리와 검증

채팅 API의 복사본을 읽어 화면에 표시합니다. 채팅·캐릭터·데이터베이스를 쓰거나
삭제하는 API, 대화 치환 API, AI 요청 API는 사용하지 않습니다. 읽던 위치와
테마 설정만 `pocketrisu.paper-reader.v1` 브라우저 저장소 키에 저장하며,
대화 본문은 저장하지 않습니다. 최대 150개 방의 위치를 기억합니다.

실제 PocketRisu 1.14.0과 Chromium에서 합성 저장 데이터로 테스트합니다.
입력창의 원래 DOM·스타일·초안 유지, 소수점 폭의 연속 페이지 넘김, CSS와 이미지,
방 전환, 재시작, 이전 버전 업데이트, 테마 해제 후 복원을 검사합니다.
실행 전후 백업에서 메시지 ID·본문·역할·시간과 방 메모·로어·변수 데이터를 비교합니다.
자세한 결과는 `dist/TEST-RESULTS.md`에 있습니다.

## 개발

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
```

`src/theme.css`가 테마, `src/reader.js`가 페이지 동작,
`src/render-message.js`가 본문 HTML/CSS/이미지 표시 코드입니다.
테스트는 `/workspace/PocketRisu`의 1.14.0 빌드,
`/workspace/pocketrisu-lab/tools`의 Playwright와 시스템 Chromium을 사용합니다.
`PAPER_PREVIOUS_PLUGIN` 환경변수에 0.1.0 JS 경로를 지정하면 실제 업데이트 과정도
검사합니다. 테스트 결과는 `test-results/runs/run-*`에 남습니다.

PocketRisu 공식 저장소는 참고·실행·테스트용입니다. 공식 저장소의 소스를 바꾸거나
커밋·푸시·PR을 만들지 않습니다. 이 프로젝트의 변경과 배포 파일은 `risussss`에만 둡니다.
